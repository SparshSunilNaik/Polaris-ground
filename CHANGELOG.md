# Changelog

All notable changes to Polaris Ground are documented in this file.

## [0.1.0] - 2026-07-31

### Added

- Tauri 2 native desktop foundation
- React and TypeScript operator interface
- Internal component and design system
- Operations Workspace
- VehicleProvider abstraction
- Deterministic MockVehicleProvider
- GroundStationService and VehicleService lifecycle
- Mission, telemetry, timeline, discovery and configuration service boundaries
- Simulated telemetry and mission progression
- Monitoring-only safety policy
- Event timeline
- Architecture documentation and Mermaid diagrams
- Automated frontend and Rust tests
- GitHub Actions CI
- macOS debug application and DMG validation

### Deliberately Not Included

- MAVLink
- PX4 transport
- Real vehicle discovery
- Networking
- USB or serial access
- Firmware flashing
- Flight controls
- Video streaming
- Engineering mode
