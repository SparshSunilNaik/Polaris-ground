# MVP Requirements

The first runnable milestone is a Tauri desktop application that displays live simulated telemetry through a replaceable `VehicleProvider`. Operators can view vehicle, link, battery, mission, autonomy, safety, and event information. Only Operate is functional; other workspaces are informative placeholders.

No MAVLink, serial/USB transport, command surface, map, firmware flashing, database, or real vehicle connection is included.
