# Product Scope

Polaris Ground is a native, cross-platform Ground Control Station for observing Polaris vehicles. It presents connection health, product-level telemetry, autonomy and safety state, mission progress, diagnostics, and future configuration workflows.

It does not own navigation, avoidance, mission execution, perception, safety decisions, VLM reasoning, or flight-control loops. The v0.3 operator surface provides only confirmation-gated arm, disarm, takeoff, land, and return-to-launch requests with explicit outcomes.
